# Cost Explorer

「管理」›「AWS」›「Cost Explorer」には、AWS Cost Explorer から、この AWS アカウントの費用を表示します。「合計」(「今月」、「月末の予測」、「先月」)、「サービス別」、「日別 (直近 30 日間)」と、タグを設定していれば「コスト配分タグ別」の費用です。

費用は、ページを開いたときではなく、1 日 1 回、定期のタスクが取得します。ページには、取得した日時を表示します。

詳しくは [Redmine AWS Cost Explorer](https://redmine-kit.github.io/redmine_aws_costexplorer/ja/) を参照してください。
