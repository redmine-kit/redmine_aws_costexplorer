# Cost Explorer

Redmine Kit AWS Cost Explorer は、Redmine が動く AWS アカウントのコストを、AWS Cost Explorer から取得して「管理」›「AWS」›「Cost Explorer」に表示します。このタブを開けるのはシステム管理者だけです。コストを取得するのは、環境変数 `REDMINE_COSTEXPLORER_ENABLED` が `true` のときだけです。そうでなければ、タブにその旨を表示します。

## タブ

金額はすべて非ブレンドコストで、Cost Explorer が返す通貨で表示します。右上に、コストを取得した日時 (「更新: … (1 日 1 回)」) を表示します。

- 「合計」: 「今月」(今日まで)、「月末の予測」、「先月」です。Cost Explorer がまだ確定していない期間には「推定」のバッジを付けます。
- 「サービス別」: サービスごとの今月と先月のコストです。サービスの前の矢印で「使用タイプ」を表示します。
- 「日別 (直近 30 日間)」: 日ごとのコストのグラフと表です。
- 「コスト配分タグ別」: `REDMINE_COSTEXPLORER_TAG_KEY` のタグの値ごとのコストです。タグのないコストは「(タグなし)」です。この環境変数を設定したときだけ表示します。タグは、Billing and Cost Management コンソールでコスト配分タグとして有効にしておく必要があります。

最後の取得が失敗したときは、取得できた最後のコストの上に「取得エラー」として日時とエラーのクラスを表示します。メッセージは Redmine のログにあります。

## コストの取得

AWS は Cost Explorer のリクエストごとに課金するため、タブを開いても Cost Explorer は呼びません。スケジュールで 1 日 1 回実行する rake タスク `redmine_kit:aws:costexplorer:refresh` が、3 件 (タグがあれば 4 件) のリクエストでコストを取得して保存します。`redmine_kit:aws:costexplorer:prune` は、90 日 (`DAYS` で変更) より前に取得したコストを削除します。最後に成功した取得のコストは残します。

## プロジェクトの料金

Redmine Kit Billing をインストールしていれば、このプラグインは料金のソースとして AWS も追加します。システム管理者が「管理」›「請求」で AWS のソースを追加し、そのアカウントをプロジェクトに割り当てると、各プロジェクトの「請求」に、そのプロジェクトに割り当てた分を表示します。
